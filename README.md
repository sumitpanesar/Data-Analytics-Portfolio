# Logistics Performance Dashboard

## Overview
This Power BI dashboard analyses logistics operations using a sample dataset based on warehouse processes.

## KPIs
- Orders Dispatched
- Trailers Processed
- Processing Time
- Stock Discrepancies
- Shift Performance

## Tools Used
- Power BI
- DAX
- Excel
- Data Visualisation

## Key Features
- Interactive dashboard
- KPI cards
- Shift slicer
- Trend analysis
- Performance comparison
